Golden Word Games advertisement files

Upload or replace creatives in this folder using these recommended filenames:

1. ad-970x90.gif              — exactly 970 x 90 pixels
2. ad-300x250.gif             — exactly 300 x 250 pixels
3. ad-spotlight-300x250.gif   — exactly 300 x 250 pixels

Supported browser image formats: GIF, WEBP, JPG/JPEG, and PNG.
WEBP or JPG is preferred for still images. GIF is suitable for animation.
Keep each file below 1 MB where possible so the game loads quickly.

After uploading a creative, open ad-config.js:
- Set the placement's enabled value to true.
- Update imageUrl if you used a different filename or extension.
- Replace destinationUrl with the sponsor's HTTPS link.
- Use openMode "fullscreen_overlay" only when the sponsor permits iframe embedding.
- Use openMode "new_tab" if the sponsor blocks iframe embedding.
