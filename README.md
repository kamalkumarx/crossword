# Golden Word Games

A senior-friendly browser game collection designed for adults aged 50+.

## Included games

- Crossword
- Word Search
- Sudoku
- Memory Match

The website is fully self-contained in `index.html` and can be opened locally or deployed directly with GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

## Current scope

This version contains the complete responsive front end. Account details and puzzle progress remain local to the browser until a secure Supabase backend is connected.
